# *Brassica* conservation gap analysis

5th November 2025

This repository contains R codes used in Taylor et al. "Enhancing crop biodiversity: distributions and conservation priorities for *Brassica* crop wild relatives". 

Please refer to the [GapAnalysis repository](https://github.com/dcarver1/GapAnalysis/tree/master) for more information about the GapAnalysis R package also used in this study.

---

## Overview of workflow

### Organisation of repository
- DistributionModels/ : contains R scripts used to generate ecological niche models and convert these to a binary format for the conservation gap analysis
- Maps/ : contains the R script used to generate interactive maps using Leaflet
- Website/ : contains files used to build a GitHub Pages platform our *Brassica* conservation gap analysis results and resources
